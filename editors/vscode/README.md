# ww_lsp for VS Code

Shows the exact_units types of WireWeaver APIs as inlay hints and hover, beside rust-analyzer. It needs the `ww_lsp` binary, on PATH or set in `ww_lsp.path`. See [ww_lsp](https://github.com/romixlab/ww_lsp). `ww_lsp.semanticTokens` turns on ww_lsp's semantic highlighting of WireWeaver syntax; VS Code then shows its tokens instead of rust-analyzer's.
